Best-gain curves use the observed best among initial16 TRAIN starts and all queried neighbors, so best-so-far is monotone by construction. Current-versus-best curves show the best currently selected state separately: paths may leave an earlier best because every step chooses a new eligible neighbor, including uphill moves. These are not atomic diffusion trajectories; each edit swaps occupancy at any occupied/vacant site. Greedy and energy-blind walks share exact first-step proposals/queries and fixed one-swap/eight-neighbor budgets. Uniform has equal caps without an identical-edit claim. All comparisons are surrogate energies relative to the same starting pool best, not the entire H0 minimum or a global optimum. Sample SD is across three paired seeds. Geometry diversity uses minimum symmetry-reduced Hamming/2 distance between16current path masks or first16eligibleuniform proposals. Current mask uniqueness is constrained by shared novelty filtering and is not spontaneous diversity proof.
