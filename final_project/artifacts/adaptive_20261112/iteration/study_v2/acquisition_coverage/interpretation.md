This post-hoc coverage diagnostic uses acquisition pools only and preserves the primary fixed-H0 yield criterion. Each method has512attempts and at most256new queries per composition/request cell; pooling three requested bins gives1536attempts and at most768physical query IDs per composition. Actual unique selected IDs are reported, so endpoint order statistics are not assumed equal-cost when novelty differs. A shared oracle evaluates overlapping method IDs only once; per-method counts must not be added as billed cost, and phase-level physical unions are shown separately. Outside-range means strictly below/above original H0 TRAIN minima/maxima, frozen by the TRAIN-only H0 range schema. No tolerance or metric was retuned. This measures observed surrogate-energy endpoints and new samples outside a finite training range, not global configurational coverage, entropy, equilibrium, DFT accuracy, or convergence. Only UMA has a frozen H0 extrema reference in this diagnostic; independent MACE fixed-bin audit remains in the core tables. Moving-target fidelity uses each checkpoint's own intervals and is descriptive, not a direct longitudinal same-property gain.
